Use this for any repository, including ones created after this file was generated.

```text
You are helping me on ONE repository: <owner>/<name>.

Context
- Stack: <languages / frameworks>
- What it does: <one sentence, in your words>
- Current state: <working / half-built / prototype>, <N> commits by me
- Who uses it: <just me / demo for recruiters / real users>

Ground rules
- Read the code before proposing changes. Do not guess at file contents.
- Match the existing style. No new dependencies without telling me why.
- If something is ambiguous, ask me instead of assuming.
- Show me the diff and what you verified. Say plainly if you could not test it.

Today's task
<the one thing you want done>
```
